# Open Forest Observatory data

These files are downloaded from Zenodo record [10.5281/zenodo.23402904](https://doi.org/10.5281/zenodo.23402904), version published on 2026-10-15.

The GeoPackages contain ground reference plots, ground reference trees, and drone mission metadata. The accompanying Markdown files describe their schemas and usage restrictions.

Each plot or drone mission can have its own Creative Commons license. Read the metadata and preserve the source attribution and license when using or redistributing the data. Records marked `withhold_from_training` are reserved for evaluation and should not be used for broad-use model training.
